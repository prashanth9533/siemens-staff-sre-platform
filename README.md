## Project Overview

This project demonstrates a cloud-native SRE platform.

### Technology Stack

- Kubernetes (k3s)
- Docker and Helm
- Argo CD GitOps
- Terraform
- Prometheus and Grafana
- Loki and Tempo
- OpenTelemetry
- Temporal workflows
- Python-based AI SRE agent

### Project Objectives

- Automate application deployments using GitOps.
- Monitor application health and performance.
- Collect centralized logs, metrics and traces.
- Define SLI, SLO and alerting rules.
- Automate incident investigation and root cause analysis.
- Implement Kubernetes security best practices.
